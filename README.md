TravenScrolls

A web application for managing and customizing character options in tabletop role-playing games.

TravenScrolls is an independent full-stack web development project focused on Dungeons & Dragons character customization. It combines a database of existing D&D classes and races with user accounts and private Homebrew content creation.

Project status: Work in progress. The application is not publicly deployed.

Features

D&D Content Database – A database containing existing D&D classes and races.

User Authentication – Users can create accounts and securely log in.

Custom Homebrew Classes – Users can create and save their own custom character classes.

Custom Homebrew Races – Users can design and save their own custom races.

Private User Content – Homebrew content is associated with its creator's account and is only visible to that user.

Technologies

Python – Backend development

Flask – Web application framework

SQL – Database management

HTML, CSS and JavaScript – Frontend development

Technical Focus

Backend development and application routing.

User registration and authentication.

Database design and persistent data storage.

User-specific data management and access control.

Handling structured game data and user-generated content.

Project Status

TravenScrolls is an ongoing personal project. Core functionality, including user accounts, the D&D content database and private Homebrew creation, has been implemented.

Further development and improvements are ongoing. The application is not currently publicly accessible.
